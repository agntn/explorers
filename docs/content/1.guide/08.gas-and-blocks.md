## Gas

```ts
const gas = await provider.getGasData?.("base");
```

Etherscan and Blockscout on their EVM chains, Mempool on Bitcoin and Litecoin, Horizon on Stellar. Nobody else, and the reasons are on the provider pages: Blockstream's fee estimates don't match the recommendation shape, WhatsOnChain and Blockbook quote per kilobyte, Peppool has no fee endpoint, Arweave prices storage per byte rather than per gas unit, Haskoin keeps no fee estimates, and the rest simply don't publish fee data.

```ts
type GasUnit = "gwei" | "sat/vB" | "litoshi/vB" | "micro-lamports/CU" | "MIST" | "stroops";

interface GasData {
  chain: ChainKey;
  unit: GasUnit; // shared by every price field below
  safeGasPrice?: string;
  proposedGasPrice?: string;
  fastGasPrice?: string;
  baseFee?: string;
  priorityFee?: string;
}
```

The unit is part of the answer. `gwei` on EVM chains, `sat/vB` on Bitcoin, `litoshi/vB` on Litecoin, `stroops` per operation on Stellar, where Horizon's fee stats give the ledger base fee, the fee most operations paid over the last five ledgers as `safe` and the 95th percentile as `fast`, with no middle tier. Fields a provider doesn't quote are absent, not zero.

## Blocks

```ts
const block = await provider.getBlockInfo?.(18_000_000, "ethereum");
```

Etherscan, Blockscout, Blockchair, Mempool on Bitcoin and Litecoin, Blockstream, Solscan, TRONSCAN, the Arweave gateways, dcrdata, WhatsOnChain, Blockbook, Haskoin and eCash Explorer. Horizon and XRPSCAN too, where a block is a ledger.

Who's missing? TONAPI and Blockberry don't expose a lookup that fits a single block number. Helius and Koios don't serve blocks, and Aptos serves nothing.

```ts
interface BlockInfo {
  number: number;
  hash: string;
  parentHash: string;
  timestamp: string; // ISO
  miner: string;
  gasUsed?: string;
  gasLimit?: string;
  txCount: number;
  baseFee?: string; // EIP-1559 chains
  // the Bitcoin-style header, from Mempool and Blockstream
  version?: number;
  merkleRoot?: string;
  bits?: number; // compact target, nBits
  nonce?: number;
  difficulty?: number;
  medianTime?: string; // ISO, median time past
  size?: number; // bytes
  weight?: number; // weight units
}
```

Most providers outside EVM still put `"0"` in both gas fields. Arweave, Decred and Stellar included. Solscan puts the block's fee rewards in `gasUsed`, in lamports. A Stellar ledger also carries its base fee in stroops in `baseFee`.

Mempool and Blockstream leave gas out completely. Why fake it? Bitcoin never had gas, and reading the block size as "gas used" was always a stretch. You get the header instead, the one the explorer already sent: version, merkle root, bits, nonce, difficulty, median time, size and weight.

```ts
import { Mempool } from "@agntn/explorers/providers/mempool";

const genesis = await new Mempool().getBlockInfo(0, "bitcoin");
genesis.merkleRoot; // "4a5e1e4baab89f3a32518a88c31bc87f618f76673e2cc77ab2127b7afdeda33b"
genesis.nonce; // 2083236893, the one Satoshi found
genesis.parentHash; // 64 zeros, genesis has no parent
```
