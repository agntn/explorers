## Gas

```ts
const gas = await provider.getGasData?.("base");
```

Etherscan and Blockscout on their EVM chains, Mempool on Bitcoin and Litecoin. Nobody else, and the reasons are on the provider pages: Blockstream's fee estimates don't match the recommendation shape, WhatsOnChain quotes satoshis per kilobyte, Peppool has no fee endpoint, Arweave prices storage per byte rather than per gas unit, and the rest simply don't publish fee data.

```ts
type GasUnit = "gwei" | "sat/vB" | "litoshi/vB" | "micro-lamports/CU" | "MIST" | "stroops";

interface GasData {
  chain: ChainKey;
  unit: GasUnit; // shared by every price field below
  safeGasPrice?: string;
  proposedGasPrice?: string;
  fastGasPrice?: string;
  baseFee?: string;
  priorityFee?: string;
}
```

The unit is part of the answer. `gwei` on EVM chains, `sat/vB` on Bitcoin, `litoshi/vB` on Litecoin, `stroops` per operation on Stellar, where Horizon's fee stats give the ledger base fee, the fee most operations paid over the last five ledgers as `safe` and the 95th percentile as `fast`, with no middle tier. Fields a provider doesn't quote are absent, not zero.

## Blocks

```ts
const block = await provider.getBlockInfo?.(18_000_000, "ethereum");
```

Etherscan, Blockscout, Blockchair, Mempool on Bitcoin and Litecoin, Blockstream, Solscan, TRONSCAN, the Arweave gateway, dcrdata, WhatsOnChain and Horizon, where a block is a ledger. TONAPI and Blockberry don't expose a lookup that fits a single block number, Helius and Koios don't serve blocks, and Aptos serves nothing.

```ts
interface BlockInfo {
  number: number;
  hash: string;
  parentHash: string;
  timestamp: string; // ISO
  miner: string;
  gasUsed: string;
  gasLimit: string;
  txCount: number;
  baseFee?: string; // EIP-1559 chains
}
```

On chains without gas the two gas fields hold `"0"`. That's the convention for every provider outside EVM, Arweave, Decred and Stellar included, so a consumer can treat the field as always present. A Stellar ledger puts its base fee in stroops in `baseFee`. Mempool and Blockstream put the block's size and weight in them instead, which the explorer labels as such.
