## Address it

```ts
const blockstream = await create("blockstream");
await blockstream.getBalance("1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa");
```

Bitcoin only, no key.

## What it reads

The Esplora wire format: `/api/address/:address`, `/api/address/:address/txs`, `/api/address/:address/utxo`, `/api/tx/:hash` and `/api/blocks/:height`, a page of blocks the provider searches for the exact height. Balances with funded and spent totals and the mempool delta, history, unspent outputs, one transaction, blocks.

## Gotchas

- `/api/address/:address/utxo` answers 400 past a few hundred unspent outputs, same as mempool.space, and that comes back as an `HTTPError` rather than a partial list.
- `/api/fee-estimates` doesn't match Mempool's recommendation shape, so gas data stays unsupported rather than approximated. Read fees through Mempool.
- Blockstream and Mempool share the mapping in `src/core/esplora.ts`, so a transaction or an unspent output from either has the same fields; only OP_RETURN decoding is Mempool's.
- In [provider selection](/guide/selection) Blockstream sits after Mempool among keyless Bitcoin providers, so it answers when Mempool is rate limiting and you didn't name a provider. That's the whole reason it's here.

## Where it lives

`src/providers/blockstream.ts`.
