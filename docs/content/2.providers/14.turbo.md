## Address it

```ts
import { Turbo } from "@agntn/explorers/providers/turbo";

const turbo = new Turbo(); // or create("turbo"), or no provider at all on Arweave
await turbo.getTxHistory("PbdTDYikdddWfNFlDt2aZokALXKe1mJVSC9TALUBNv8", "arweave", { sort: "asc" });
```

That wallet got its first AR in May 2019. arweave.net starts its history years later. Turbo starts on the right day.

## Why first?

AR.IO's own docs call this index comprehensive, and for layer 1 transfers it is. Old wallets, tagged posts from those first years, all there. So an Arweave read without a provider lands here first. Does it fail with a 5xx or a timeout? The read moves to [ar.io](/providers/ario) once.

## Gotchas

- Some bundled data items from around block 1,700,000 never made it into this index. [ar.io](/providers/ario) has them.
- It's the same class as [arweave.net](/providers/arweave), only the default gateway differs. Windows, tags, fees and pending rows behave as listed there.
- Data items carry their real bundle id in `raw.bundledIn`, where arweave.net leaves it empty.

## Where it lives

`src/providers/turbo.ts`, on top of `src/providers/arweave.ts`.
