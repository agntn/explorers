## Address it

```ts
import { Ario } from "@agntn/explorers/providers/ario";

const ario = new Ario(); // or create("ario")
await ario.getTxDetail("mILC0VAVV4cGR8tVlzMEb2GgE_Krfi2yGRV8rrSNgDc", "arweave");
```

That's a data item bundled around block 1,700,000. Turbo doesn't know it. ar-io.dev does, bundle id included.

## Why second?

It knows the old layer 1 transfers too, and some old uploads Turbo lost. But it once ran past the 15-second timeout on a tag filter Turbo answered in under a second. So it waits behind [Turbo](/providers/turbo) and takes over when Turbo falls over. Digging through uploads from that era? Name `ario` yourself.

## Gotchas

- It's the same class as [arweave.net](/providers/arweave), only the default gateway differs. Windows, tags, fees and pending rows behave as listed there.

## Where it lives

`src/providers/ario.ts`, on top of `src/providers/arweave.ts`.
